# 无限图片墙视觉调整设计

## 目标

消除图片底部露出的彩色圆角底板，让不同尺寸和比例的图片都以一致尺寸显示；同时用低对比度点阵替代纯色黑色背景，使页面更有层次而不干扰图片内容。

## 视觉方案

- 所有图片卡片采用固定 `3:4` 比例。
- 图片完整铺满卡片区域，使用 `object-fit: cover` 自动等比缩放，并在比例不符时从中心裁切。
- 卡片容器不再显示紫色或其他装饰底色，避免图片未铺满时露出底部色块。
- 图片自身保留轻微圆角，以维持现有图片墙的柔和观感；不添加独立底板、边框或底部装饰。
- 页面底色采用炭黑色。
- 背景叠加稀疏点阵：点间距为 `26px`，点为低透明度微灰白色，点径约 `1px`。

## 交互与布局

- 保留现有鼠标拖拽、无限循环换位和悬停放大交互。
- 不改变图片数量、分行结构或 GSAP 动画逻辑。
- 保留现有桌面与移动端的整体缩放策略，只调整卡片比例和图片填充规则。
- 图片继续禁止原生拖拽和文本选择，避免与图片墙拖拽交互冲突。

## 实现边界

本次优先通过 CSS 完成，不删除 `.photos_line_photo` 容器，也不更改 JavaScript 使用的选择器和尺寸读取方式。这样可以让现有无限循环计算继续使用实际卡片宽高，降低回归风险。

## 验收标准

1. 任意宽高比图片都显示为一致的 `3:4` 卡片。
2. 图片无拉伸变形，且完整铺满卡片，不出现底部或侧边装饰色块。
3. 页面背景可见均匀、稀疏、低对比度的微灰白点阵。
4. 拖拽、无限循环、悬停放大在桌面端保持正常。
5. 现有响应式缩放规则下，窄屏页面无新增溢出或明显布局异常。

## 验证方式

- 在浏览器中检查多张不同比例图片的裁切与铺满效果。
- 拖拽图片墙跨越四个边界，确认循环换位连续。
- 分别检查桌面宽屏、接近方形窗口和窄屏窗口。
- 悬停图片，确认放大效果仍被卡片边界正确裁切。
