# 宇宙科幻项目总览页设计

## 目标

把仓库根目录的项目导航页重构成一个成熟、精致、带叙事感的宇宙科幻展示页，同时保留它作为学习项目索引的核心效率：访客能快速理解这是“86 个前端交互实验”，能筛选现有项目、查看完成状态并进入各个演示。

页面面向两类访客：回顾练习进度的作者本人，以及通过 GitHub Pages 浏览作品的访客。页面的单一任务是让项目集合既值得探索，又容易使用。

## 选定方向：深空档案馆

采用深蓝黑宇宙背景、观测档案式排版、轨道刻度和克制的冰蓝高光。视觉像一份正在持续更新的深空任务档案，而不是霓虹控制台或通用 SaaS 卡片墙。

参考线上沉浸式作品集的共同模式：固定环境层承载氛围，HTML 内容保持可读和可操作，滚动进度驱动场景变化。实现原则参考 Codrops 的 [Three.js 滚动动画教程](https://tympanus.net/codrops/2022/01/05/crafting-scroll-based-animations-in-three-js/) 和 [滚动场景案例](https://tympanus.net/codrops/2026/04/28/more-than-a-portfolio-building-a-scroll-driven-3d-world-with-something-to-say/)。本项目不复制案例代码，只采用其分层和动效编排思路。

## 视觉系统

### 色彩令牌

- `void`: `#03060B`，页面主背景。
- `deep-space`: `#07111E`，内容层与深色表面。
- `starlight`: `#EAF6FF`，主文字。
- `signal`: `#74D7FF`，交互、高光和轨道信号。
- `muted`: `#8197AA`，说明文字与刻度。
- `warning`: `#FF9D6C`，瑕疵、跳过等异常状态。

所有色彩、字号、间距、边框和运动时长通过 CSS 自定义属性集中管理。

### 字体

- 展示标题使用 `Bodoni Moda`，营造天文档案和编辑出版物的气质。
- 中文正文使用 `Noto Serif SC`，保持中文阅读的成熟感。
- 数据、标签和项目编号使用 `IBM Plex Mono`，形成观测仪器的技术语气。
- 网络字体加载失败时回退到本地 serif 与 monospace 字体，不影响布局与功能。

### 布局概念

页面是一份纵向展开的航行档案：首屏建立世界观，进度带交代规模，项目区像观测记录一样逐行显现，页尾形成任务续航提示。

```text
┌────────────────────────────────────────────────────┐

│                                                    │
│ 数字宇宙                                           │
```

### 记忆点

首屏右侧是一颗超出视口边界的“观测行星”，外侧有偏心轨道和测量刻度。滚动时行星缓慢上浮并改变光照，轨道以不同速度漂移；它是贯穿页面的单一主特效。其他装饰保持安静，避免平均用力。

## 页面结构

### 1. 固定环境层

- 一个全屏固定 Canvas 绘制轻量星场，依据指针位置和滚动速度产生微弱视差。
- CSS 伪元素生成噪点、暗角和稀薄星云，不使用大体积视频或 3D 模型。
- 行星、轨道和测量刻度使用 CSS/SVG 构成，便于响应式缩放。
- 环境层设置 `pointer-events: none`，不阻挡页面操作。

### 2. 首屏任务引导

- 顶部导航只包含项目标识、当前已记录数量和简短状态，不添加无实际去向的菜单。
- 主标题为“数字宇宙 / 探索档案”，副标题说明这是 86 个前端交互实验的持续记录。
- 使用滚动提示和“进入项目档案”锚点，均跳转到项目列表。
- 现有总数、完成数和完成率保留，并由 DOM 中的项目状态动态计算。

### 3. 项目档案

- 保留分类筛选，但视觉改为一排观测频段标签，支持键盘焦点和明确的选中状态。
- 桌面端不采用浮起卡片。项目以宽幅档案行排列：编号、标题、技术、状态和进入动作形成稳定列。
- 行悬停时通过横向扫描线、编号偏移、标题亮度和箭头位移反馈，不整体上浮。
- 小屏幕下档案行折叠成紧凑的两层布局，而不是横向溢出。
- 保留分页，每页数量继续由脚本控制；切页后平滑滚动回档案标题并重新执行轻量揭示。

### 4. 页尾

- 用“Transmission continues / 探索仍在继续”回应项目持续更新的属性。
- 显示当前年份、GitHub Pages 托管说明和已记录项目数，不添加虚构社交链接。

## 动效编排

### 首次进入

1. 页面从黑场淡入，星场先出现。
2. 轨道线绘制，行星由右侧缓慢进入。
3. 主标题按整行遮罩揭示，状态信息随后出现。
4. 动画总时长控制在约 1.4 秒，访客无需等待才能操作。

### 滚动过程

- 使用 `requestAnimationFrame` 合并滚动更新，驱动行星 `translate3d`、轨道旋转和背景星层速度。
- 项目行通过 `IntersectionObserver` 分批揭示，避免在每次滚动时遍历全部元素。
- 首屏离开后，标题与行星产生不同速度的纵向位移，形成景深；不劫持原生滚动。
- 顶部细线显示页面阅读进度，像任务航迹而不是普通进度条。

### 指针反馈

- 保留自定义目标光标的概念，但缩减为信号点与细环，不再让四角框覆盖大面积按钮。
- 指针经过可操作元素时扩大并显示磁吸式轻微跟随。
- 触控设备、粗指针设备和减少动画偏好下自动禁用自定义光标。

### 减少动画模式

`prefers-reduced-motion: reduce` 时关闭星场移动、视差、平滑滚动和循环旋转，只保留短促透明度变化；筛选、分页和链接功能完全不受影响。

## 技术方案

继续采用现有的纯 HTML、CSS 和 JavaScript，不引入构建工具。现有 GSAP CDN 可用于一次性首屏时间线和交互缓动；核心内容与筛选分页不依赖 GSAP，CDN 加载失败时页面仍然可用。

- `index.html`：重组语义结构，保留 26 个项目的真实信息与链接，保留用户对第 25 项“星空宇宙背景”的修改。
- `style.css`：重写为令牌化的响应式视觉系统。
- `script.js`：拆分为星场、滚动场景、筛选分页、统计和光标五个小模块；使用事件委托减少重复按钮监听。

项目数据暂时仍放在 HTML 中，避免为 26 条静态内容额外引入数据加载和模板层。未来项目增加时仍按现有结构追加档案行。

## 数据与交互流程

1. DOM 加载后读取所有 `.project-entry`，计算总记录数、完成数和分类计数。
2. 筛选点击更新活动分类，过滤项目集合，重置为第一页。
3. 分页从过滤后的集合切片，更新可见状态和页码。
4. 可见项目通过原生链接进入对应目录；无需脚本才能跳转。
5. 筛选与分页变化后更新无障碍状态，并把焦点保持在触发控件附近。

## 容错与边界

- JavaScript 禁用时，所有项目仍完整显示，链接仍可访问；筛选和分页作为渐进增强。
- Canvas 不可用时显示纯 CSS 星云背景。
- GSAP 加载失败时跳过高级时间线，CSS 负责静态最终状态。
- 网络字体加载失败时使用本地回退字体。
- 空分类不会产生第 0 页；显示“该观测频段暂无记录”并禁用分页。
- 页面初始化只绑定一次事件，避免当前代码中重复生成“查阅”按钮和分散监听的问题。

## 性能与可访问性

- Canvas 根据设备像素比设上限，并在标签页隐藏时暂停动画。
- 窗口调整使用节流，重新计算星场尺寸而不反复创建粒子。
- 动画只改变 `transform` 和 `opacity`，避免滚动期间布局抖动。
- 使用语义化标题、导航、列表和链接；筛选按钮含 `aria-pressed`。
- 所有文字与状态达到足够对比度，键盘焦点使用高亮轨道线而不是仅依赖颜色。
- 移动端隐藏纯装饰细节，确保项目入口最小触控高度为 44px。

## 验证方案

- 在桌面宽屏、常见笔记本宽度、平板和手机尺寸检查布局。
- 验证全部分类计数、筛选、分页、状态统计和 26 个项目链接。
- 验证 GSAP、Canvas 或网络字体不可用时的降级行为。
- 验证键盘顺序、焦点可见性、减少动画偏好和触屏行为。
- 使用浏览器检查无横向滚动、无控制台错误，并对首屏与项目区截图做视觉复核。

## 不在本次范围

- 不重构 `projects/` 下的单个演示页面。
- 不新增后端、搜索、用户账户或数据持久化。
- 不引入 Three.js、WebGL 着色器、视频背景或大型 3D 素材。
- 不使用来源不明的整段第三方页面代码。
